# Timeless Grotesk (Untitled theme)

WOFF2 static cuts from **Timeless Type Family 1.094** (`Sans-Grotesk`), registered in CSS as `"Timeless Grotesk"` to match Untitled / `GUI.md` tokens.

| File | CSS weight | Theme role |
| --- | --- | --- |
| `TimelessSans-GroteskRegular.woff2` | 400 | ui/brand/editorial/data regular |
| `TimelessSans-GroteskMedium.woff2` | 500 | medium |
| `TimelessSans-GroteskSemibold.woff2` | 600 | heavy |

Internal PostScript family is “Timeless Sans Grotesk”; `@font-face` aliases it to `"Timeless Grotesk"` without substituting a different design.
